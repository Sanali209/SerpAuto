Шаг 5/14

🪟 UI/UX — Desktop GUI (Dear PyGui)

GUI доступен в режимах ARCHITECT и TEACHER. Управляется через GUIDebugSystem (TELEMETRY фаза). DPG: docking, 1600x900 viewport.

🖥️ Экраны (Windows)

Control Deck

windows/control_deck.py — Панель управления: Play/Pause/Step, TPS slider, REC (dataset recording), Save/Load snapshot.

World Outliner

windows/outliner.py — Список всех Entity с фильтром. Клик = выбор сущности. SelectionService управляет состоянием выбора.

Inspector

windows/inspector.py — Инспектор выбранного объекта. Для ENTITY: показывает все компоненты с AutoUIBuilder (редактирование полей). Для NODE: показывает параметры BT-ноды.

Viewport

windows/viewport.py — 3D viewport. Отображает рендер ModernGL через динамическую текстуру. Клик → VIEWPORT_CLICK → PossessionSystem (raycast → selection).

Behavior Tree Editor

graph/bt_editor.py — Визуальный редактор BT. Панель нод (RegistryV2.get_nodes_by_category). Рендерит дерево с цветовой кодировкой статусов (SUCCESS=green, FAILURE=red, RUNNING=blue). Авто-раскладка.

Perception Pipeline Editor

graph/perception_editor.py — Визуализация pipeline (Screen → Crop → Grayscale → Output). Статическая на текущий момент.

Global Swarm Roster

windows/roster.py — Таблица агентов: ID, BT Status, FPS, CPU, HP, Stamina. Кнопка Focus → выбор.

Action Timeline

windows/timeline.py — Визуализация истории действий (timeline за 10 секунд). Цветовая кодировка: move=синий, click=красный, key=зелёный.

Imitation Learning Monitor

windows/imitation.py — Сравнение Human vs AI действий. График loss. Shadow queue для AI-предсказаний.

🔁 User Flows

  1. Entity Selection: Outliner → клик → SelectionService → Inspector (auto UI)
  2. Viewport Interaction: Viewport → клик → event bus → PossessionSystem → raycast → entity possession
  3. Engine Control: Control Deck → Play/Pause/Step → event bus → Engine
  4. BT Editing: Select entity → BT Editor отображает дерево → интерактивное редактирование

🎨 UX Patterns

  • Auto UI Generation: AutoUIBuilder → DPG виджеты из Pydantic полей
  • Event-driven GUI: Все GUI-компоненты общаются через EventBus
  • Selection-driven: Глобальное состояние выбора влияет на Inspector, BT Editor, Timeline
  • Docking: DPG docking-space для перетаскивания окон
