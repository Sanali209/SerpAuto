📊 SWOT + Tech Debt + Roadmap

SWOT Analysis

✅ Strengths

  • Чистая ECS-архитектура
  • Pydantic-first data layer с авто-UI
  • Strategy Pattern для режимов
  • Визуальный BT Editor
  • Gymnasium-совместимость для RL
  • Богатый perception pipeline (CV, OCR, скриншоты)
  • Хорошая документация (des_docs + Diátaxis)

❌ Weaknesses

  • Дублирование кода (SelectionService, RegistryV1/V2)
  • Hardcoded perception pipeline
  • Смешение async + sync (блокировки event loop)
  • Нет README.md в корне
  • Perception pipeline editor — статический, не редактируемый
  • Scene система не интегрирована

🌍 Opportunities

  • Интеграция YOLO/ONNX для real-time object detection
  • FastAPI REST bridge для production
  • Playwright для веб-автоматизации (если вернуться к SerpAuto)
  • Визуальное редактирование perception pipeline
  • Сериализация/загрузка Behavior Trees
  • Multi-agent RL через существующий swarm модуль

⚠️ Threats

  • DearPyGui может быть заброшен (меньше комьюнити, чем PyQt)
  • Async + sync смешение ведёт к трудноотловимым багам
  • Нет CI/CD, нет автоматического тестирования GUI
  • Проект может быть "over-engineered" для демо-версии
