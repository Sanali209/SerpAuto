📦 Scene Pipeline (Pass 2 discovery)

NEW SceneManager (core/scene/) — полноценная система сохранения/загрузки сцен:

  • SceneData (Pydantic) — metadata + systems + entities + global_config
  • SceneSaver — сериализует World snapshot + Registry system metadata в JSON
  • SceneLoader — загружает JSON → Pydantic валидация → world.restore_snapshot() + Registry.reset_system_metadata() + system config overrides
  • SceneManager — оркестратор с load_scene / save_scene / transition_to_scene
  • SystemConfig — позволяет переопределять priority/tick_rate систем в сцене
