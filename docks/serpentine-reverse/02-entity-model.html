📊 Entity System — ECS Models & Types

🏛️ Core ECS

EntityID

serpentine/core/entity.py — NewType над UUID. Сущности — просто UUID-идентификаторы.

BaseComponent

serpentine/core/component.py — Pydantic BaseModel с ConfigDict(arbitrary_types_allowed=True). База для всех компонентов.

World

serpentine/core/world.py — Хранит Set[EntityID] и Dict[Type[Component], Dict[EntityID, Component]]. Кэширует запросы (query_cache). Операции: create/delete entity, add/remove/get/has component, get_entities_with (cache-инвалидация), snapshot/restore (сериализация JSON).
