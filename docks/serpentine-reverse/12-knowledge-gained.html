🧠 Knowledge Gained — Lessons & Patterns

📐 ECS с Pydantic компонентами

Категория: pattern

Суть: Компоненты ECS как Pydantic модели — data validation + serialization (snapshot JSON) + auto UI из коробки (AutoUIBuilder).

Применимость: Любой ECS-проект на Python. Элегантное решение для data layer.

🔄 Mode Strategy через Registry

Категория: pattern

Суть: Системы регистрируются с метаданными (фаза, режимы, приоритет). ModeStrategy просто фильтрует Registry. Добавление новой системы = 1 декоратор.

Применимость: Приложения с несколькими режимами работы (dev/prod/test/teacher).

🚀 Double Queue для Imitation Learning

Категория: pattern

Суть: action_queue (для выполнения) + shadow_queue (для AI-предсказаний). ImitationLearningMonitor сравнивает обе очереди.

Применимость: IL/RL системы с Human-in-the-loop.

⚠️ DearPyGui + asyncio — потенциальный anti-pattern

Категория: anti-pattern

Суть: Синхронный GUI в async event loop. DPG.render_dearpygui_frame() вызывается как system update, блокируя event loop.

Альтернатива: QThread (PyQt) или отдельный процесс.

🔍 Fixed Timestep Accumulator

Категория: lesson

Суть: Системы с tick_rate имеют аккумулятор dt. Tick выполняется пока accumulator >= target_dt, предотвращая spiral of death.

Применимость: Game engines, физические симуляции.

🛠️ AutoUIBuilder — runtime UI из data models

Категория: tool

Суть: AutoUIBuilder рекурсивно строит DPG-виджеты из Pydantic полей (str→input, int→drag, bool→checkbox, Enum→combo, BaseModel→tree_node).

Применимость: Любой десктопный инструмент с runtime-редактированием данных (GUI для конфигов, отладчики ECS).

🗃️ Query Cache в ECS

Категория: lesson

Суть: World._query_cache кэширует результаты get_entities_with(*types). Инвалидация при add/remove компонента. Использует smallest-set-first оптимизацию.

Применимость: Любая ECS имплементация.
