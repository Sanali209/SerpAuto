🧩 Новые паттерны (Pass 2)

Scene as Snapshot + Registry Override

NEW Где: core/scene/

Что: Scene = JSON файл, содержащий полный snapshot мира (entities + components) + system config overrides (priority, tick_rate). SceneLoader парсит Pydantic → world.restore_snapshot() → Registry.reset_system_metadata() → system config override.

Proxy Pattern — Mock DPG в тестах

NEW Где: tests/conftest.py

Что: DearPyGui полностью мокируется через MagicMock, включая context managers (window, node_editor, node, theme, group, child_window). Позволяет тестировать GUI-логику без дисплея.
