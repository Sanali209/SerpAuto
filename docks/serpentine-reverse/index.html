🏆 Топ находок

  1. ECS с Pydantic: data validation + JSON snapshot + auto UI — треугольник продуктивности
  2. Scene как Snapshot: Scene = JSON (entities + components) + system config overrides (priority, tick_rate)
  3. Dual Queue IL: action_queue + shadow_queue для Human-AI сравнения в реальном времени
  4. Mode Strategy: 4 режима через Registry-фильтрацию (декор регистрация → метаданные → стратегия)
  5. BT Editor с live-статусами: SUCCESS=green, FAILURE=red, RUNNING=blue — визуальная отладка AI
  6. Auto UI Builder: Pydantic model → DPG widgets — рекурсивно, с Enum/BaseModel/list/dict поддержкой
  7. Mock DPG Proxy: conftest мокает DearPyGui (включая context managers) для тестов GUI-логики
  8. Perf тесты: 1000 entities scene loading < 500ms, 10k entities cached query < 1ms

⚠️ Ключевые проблемы (обновлено Pass 2)

  • ❌ Дубли SelectionService + Registry — не мержены, core/selection vs gui/selection
  • ❌ Perception pipeline hardcoded — не из конфига, Crop + Grayscale только
  • ❌ Async + Sync смешение — engine async, PyAutoGUI/Tesseract sync → блокировки
  • ❌ Scene не интегрирована в engine loop — SceneManager существует, но не связан с Engine.run()
  • ❌ GUI пересоздаёт UI каждый frame — Outliner и Roster — O(n) кадр
  • ❌ FastAPI, YOLO, Playwright не используются — 3 библиотеки в requirements без кода
  • ❌ CONTINUOUS_LEARNING режим — enum-заглушка
  • ⚠️ Matrix math в RenderSystem — 2D rotation, Z=0, потенциально не для 3D
