❓ Open Questions

1. Почему Playwright в зависимостях, но не используется?

Гипотеза: Планировалась веб-автоматизация для SerpAuto (SERP), но проект переориентировался на игровой движок.

2. Registry и RegistryV2 — почему два?

Гипотеза: RegistryV2 — рефакторинг с добавлением поддержки window registry. Registry не удалён для обратной совместимости. Надо мержить.

3. SelectionService в двух местах — почему?

Где: core/selection.py и systems/gui/selection.py — дубликаты с разными event names.

Гипотеза: Рефакторинг не завершён. GUI SelectionService использует GUIEventBus напрямую.

👁️ Blind Spots

Security

  • PyAutoGUI FAILSAFE=true — хорошо, но может быть обойдён.
  • Нет ограничений на действия AI (может кликать куда угодно).
  • Snapshot JSON — нет валидации при загрузке (может привести к arbitrary object creation).

Performance

  • Outliner удаляет и пересоздаёт UI каждый frame — дорого для >50 entity.
  • Query cache в World не сбрасывается по таймеру — только на изменение компонента.
  • DatasetLoggerSystem открывает/закрывает файлы каждый фрейм.

Scalability

  • ActionExecutionSystem обрабатывает 1 intent/tick — не scale для многих агентов.
  • GUI в том же процессе — блокирует engine frame при тяжёлых операциях.
  • Нет worker threads для PyAutoGUI/OpenCV.

⚖️ Architectural Criticism

1. Смешение GUI и Engine в одном event loop

Проблема: DearPyGui и async engine работают в одном потоке. DPG.render_dearpygui_frame() вызывается в TELEMETRY phase, что может блокировать tick.

Альтернатива: Вынести GUI в отдельный процесс/поток, общаться через IPC.

2. Hardcoded perception pipeline

Проблема: Список нод в коде, не из конфига. Нельзя переключить pipeline без редактирования кода.

Альтернатива: JSON/YAML конфиг + фабрика нод.

3. Нет сериализации Behavior Tree

Проблема: BT создаётся в коде (snake_demo.py, gym_wrapper.py). Нельзя сохранить/загрузить дерево.
